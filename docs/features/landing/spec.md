# Landing page

## Purpose

The first page someone sees on nox.garden: start reading at once, or sign in.

## Behaviour

Under "Start reading", one note says where your data goes: nox has no server
that stores it, link previews on the web pass through a proxy, and both are
open source, with a link to each repository.

## Acceptance

- LANDING-1: The landing page says nox has no server that stores your data,
  names the link-preview proxy as web-only, and links to the source of nox
  (github.com/junkpiano/nox) and of the proxy (github.com/junkpiano/nostr-proxy).

## Not doing

- Listing the other third parties (image hosts, X embeds, avatars) here; the
  privacy policy lists them, and the landing note stays one line.

## Open

None.
